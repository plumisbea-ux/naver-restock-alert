구매할 수 없는 품절 화면을 끝점으로 두지 않습니다. 고객의 선택 옵션과 톡톡 사용자 식별값을 연결해 재입고 시점까지 보관합니다.

1

품절 옵션 확인

고객이 상품 페이지에서 원하는 품절 옵션을 선택하고 톡톡 문의로 이동합니다.

2

대기 등록

상품 번호와 옵션을 매핑합니다. 고객은 톡톡 또는 톡톡과 SMS 수신을 선택합니다.

3

재입고 발송

재고가 0에서 1 이상으로 바뀌면 해당 옵션의 대기 고객에게 상품 링크를 보냅니다.

정보만 남깁니다

화려한 대시보드보다 실제 재고 결정과 발송 확인에 필요한 기록을 우선합니다.

정확한 상품 매핑

스마트스토어 상품번호, 내부 상품 ID, 옵션 ID를 함께 저장해 다른 옵션으로 잘못 발송되는 문제를 막습니다.

발송 결과 구분

실제 API 발송, mock 기록, 실패 상태를 구분합니다. 실패한 대기자는 발송 완료로 처리하지 않습니다.

수신 채널 관리

톡톡 기본 수신과 Profile API 동의 기반 SMS 수신을 분리하고, 동의 철회 시 전화번호를 삭제합니다.

대기 수요 보고서

상품·옵션별 대기자, 발송 건수, 상품 확인 흐름을 한곳에서 확인합니다.
